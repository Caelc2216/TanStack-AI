# Tiny teaching examples (not the assignment solution)

These are examples Claude can point to when explaining syntax. They deliberately use a different resource.

```ts
const key = ['products', productId]
```

```ts
const result = await fetch('http://localhost:3001/employees')
if (!result.ok) throw new Error('Request failed')
```

```ts
const queryClient = new QueryClient()
```

Keep examples brief and teach concepts before asking the student to implement them.
